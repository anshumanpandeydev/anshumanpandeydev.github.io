Problem
Researching a prospect, scoring the lead, and drafting a tailored cold email is slow, manual work that sales teams repeat for every single company.
Built
A multi-agent pipeline on Google's Agent Development Kit + Gemini 2.5 Flash: an orchestrator delegates to four specialized agents — live company research, lead scoring, cold-email drafting, CRM logging to Google Sheets — passing typed Pydantic outputs and shared session state between them. Deterministic tools do the scoring math; the LLM does the reasoning. Exposed as a 5-tool MCP server with a streaming Gradio UI.
Impact
Company name in, researched + scored lead with a ready-to-send email out — one automated pass, running entirely inside free-tier quotas thanks to a shared rate limiter.
